# Source Directory

All source files used to generate the dictionary should be stored in this directory.

`perl.txt` holds the names of Perl's built-in functions and keywords, as listed in
[perlfunc](https://perldoc.perl.org/perlfunc) and [perlsyn](https://perldoc.perl.org/perlsyn), and its pragmas, as
listed in [perlmodlib](https://perldoc.perl.org/perlmodlib#Pragmatic-Modules). It holds names only, no text from
Perl's documentation.
