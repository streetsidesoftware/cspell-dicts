# MATLAB Samples

Short MATLAB scripts that `pnpm test` spell checks with this dictionary. They aren't part of the npm package.

Some of them follow examples in the MATLAB documentation:

- [signal_processing.m](./signal_processing.m): the noisy signal example on the
  [`fft`](https://www.mathworks.com/help/matlab/ref/fft.html) page.
- [data_visualization.m](./data_visualization.m): the `X .* exp(-X.^2 - Y.^2)` surface used on the
  [`surf`](https://www.mathworks.com/help/matlab/ref/surf.html) page.
- [numerical_methods.m](./numerical_methods.m): the ODE examples on the
  [`ode45`](https://www.mathworks.com/help/matlab/ref/ode45.html) page.
- [linear_algebra.m](./linear_algebra.m): the
  [backslash operator](https://www.mathworks.com/help/matlab/ref/double.mldivide.html) and
  [`eig`](https://www.mathworks.com/help/matlab/ref/eig.html) pages.
- [data_analysis.m](./data_analysis.m): no known origin.
